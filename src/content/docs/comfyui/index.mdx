Isekai Comfy Node is a comprehensive collection of custom nodes for [ComfyUI](https://comfyui.com/) that integrates well with your [Isekai Core](/overview/start-here) deployment.

With **35 nodes** across multiple categories, you can manipulate images with 22 professional-grade effects and transforms, integrate with 4 different LLM providers, manage complex prompt workflows, and upload directly to Isekai.

<Aside type="note">
If you don't use Isekai Core, you can also skip the integration and use the image compression and string utility nodes standalone within ComfyUI. These nodes are useful for regular batch processing workflows and will work as is, even without an API key.
</Aside>

## Features Overview

<CardGrid>
  <Card title="Image Manipulation" icon="seti:image">
    22 professional-grade nodes for image effects, transforms, and blending. Blur, sharpen, color grading, vignette, chromatic aberration, rotate, scale, crop, and more.
  </Card>
  <Card title="AI Integration" icon="star">
    Generate captions and descriptions using Claude, OpenAI GPT, Google Gemini, or local Ollama models for automated metadata.
  </Card>
  <Card title="String Utilities" icon="document">
    Dynamic string selection, concatenation, tag lookup, round-robin cycling, and file loading for building complex prompts.
  </Card>
  <Card title="Cloud Upload" icon="rocket">
    Upload images directly to Isekai or S3-compatible storage (AWS S3, Cloudflare R2) with built-in compression.
  </Card>
</CardGrid>
